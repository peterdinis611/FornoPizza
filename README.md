# Forno

Základný Blazor e‑shop pre pizzeriu. Katalóg, košík, jednoduchá objednávka bez platby.

```bash
cd forno
dotnet run
```

Otvorte `http://localhost:5036`.

## Čo je hotové

- pec (úvod)
- menu a detail pizze
- košík
- objednávka (iba formulár, bez platobnej brány)

Ďalšie veci (platba, kuchyňa, účty, admin) neskôr.
